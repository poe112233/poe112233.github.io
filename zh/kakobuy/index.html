OE 如何与该渠道协作

OE 不在页面上写出固定的周转时间或费率，因为这些取决于具体商品、货源与收货地。下单前，工作台会与你逐项确认。

  1. 你提供商品信息——型号、配色或参考编号，以及适用的尺码。
  2. 工作台针对该品类，比对其自有货源关系进行寻货。
  3. 你收到货源可用性、成色说明以及需要注意的细节，再做决定。
  4. 在你确认之后，订单才进入履约流程。

常见问题

Kakobuy 覆盖哪些品类？

腕表与精密制品。球鞋属于 Oopbuy 与 Litbuy，服饰属于 Uidbuy 与 Hipobuy。

成色是怎么说明的？

工作台会为每一件单独撰写成色说明，并在你确认之前发给你。说明覆盖哪些细节取决于具体商品，如果你在意某一点，可以直接提出。

可以指定找某一款型号吗？

可以。把参考编号发过来，工作台会回复能够找到的货源，以及该件的记录情况。

OE 其他渠道

Oopbuy

Oopbuy 是 OE 的球鞋工作台。它面向在意发售节奏、全尺码覆盖，以及不想为找一双经典款四处奔波的买家。.

球鞋

Uidbuy

Uidbuy 是 OE 的服饰与外套工作台。它的组织方式就像衣橱真实的搭建过程——按季节推进，落在经得起时间的基础上。.

服饰

Hipobuy

Hipobuy 是 OE 处理「有存在感单品」的工作台。精选视角贴近秀场，但刻意保持平衡——每一件标志性单品，都会搭配一件你真正能日常穿着的衣服。.

服饰

Litbuy

Litbuy 是 OE 面向收藏者的工作台。重点放在那些鞋盒、品相与配色和鞋子本身同样重要的鞋款上。.

球鞋

Boonbuy

Boonbuy 是 OE 处理「不属于单一品类」的订单的工作台。如果你的订单同时包含球鞋、一块腕表和一件外套，就是在这里合并的。.
