How OE works with this channel

OE does not publish fixed turnaround or fee figures for a channel, because they depend on the item, the source and the destination. The desk confirms the specifics with you before an order is placed.

  1. You send the item — model, colourway or reference, plus size where relevant.
  2. The desk checks sourcing against its own relationships for this category.
  3. You receive availability, condition notes and any caveats before committing.
  4. Only after you confirm does the order move to fulfilment.

Frequently asked questions

What kind of items does Oopbuy handle?

Sneakers, primarily. Both limited releases and classic pairs run through this desk. Watches sit with Kakobuy; apparel sits with Uidbuy and Hipobuy.

How do I find out whether a size is available?

Send the model, colourway and the size you want. The desk checks across the size run and comes back with what it can source.

Can Oopbuy handle an order that mixes categories?

A basket spanning several categories is better routed through Boonbuy, which is set up for mixed orders. Single-category sneaker orders are usually faster here.
